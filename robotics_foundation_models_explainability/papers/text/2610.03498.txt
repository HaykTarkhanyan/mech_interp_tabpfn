Abstract: Adversarial patches can disrupt Vision-Language-Action (VLA) models by manipulating visual observations, leading to failures in robot control. However, it remains poorly understood which internal mechanisms underlie these failures and how targeted interventions can mitigate them. In this work, we mechanistically analyze VLA representations using a sparse autoencoder (SAE) and identify a feature whose activation strongly correlates with the presence of an adversarial patch. Based on this analysis, we suppress the identified feature at inference time only when a linear probe detects an attack. This intervention improves robustness without the cost of fine-tuning the VLA. We evaluate our method against VLA adversarial patch attacks on LIBERO-10. Conditional intervention improves success rate under intermittent attacks, whereas continuously applying the same intervention substantially degrades policy performance. These results show that attack-related internal representations can provide useful targets for VLA adversarial defense and that controlling when to intervene is important for limiting disruption to nominal policy behavior.
Keywords: Vision-Language-Action Models, Adversarial Robustness, Mechanistic Interpretability
1 Introduction
Adversarial patches can disrupt vision-language-action (VLA) policies by altering the visual observations used for robot control [1, 2]. Existing VLA defenses modify either the inputs, through image preprocessing [3], or the model parameters, through adversarial fine-tuning [2]. Adversarial finetuning, however, incurs the computational cost of additional policy training. We ask whether VLA

robustness can instead be improved by directly targeting attack-related internal features at inference time, without fine-tuning the policy.
Mechanistic interpretability provides a basis for investigating this question. Recent studies have identified internal directions and sparse autoencoder (SAE) features whose manipulation influences VLA behavior [4, 5, 6, 7]. These studies primarily examine nominal behavior, leaving the use of such features for adversarial defense underexplored. However, indiscriminately suppressing attackrelated features may also disrupt nominal policy behavior. An effective defense therefore requires examining both which feature to target and when to suppress it.
We investigate these questions through SAE-based analysis and conditional intervention in VLA representations. We identify an SAE feature associated with patch presence and train a linear probe to detect attacks from the VLA’s internal state. At inference time, we suppress the feature’s contribution only when the probe detects an attack, while keeping the VLA parameters fixed. On LIBERO10 [8] under Untargeted Action Discrepancy Attack (UADA) [1], this conditional intervention improves task success under intermittent attacks, whereas continuous suppression of the same feature substantially degrades performance. Our results suggest that internal features associated with adversarial patches can serve as targets for VLA defense, and that intervening only during detected attacks limits disruption of nominal behavior.

3 Methodology: Conditional Feature Intervention

Problem Setup. Our goal is to improve task success under adversarial patch attacks while limiting
performance degradation under clean observations. A VLA policy generates an action at = π(ot, l) from a visual observation ot and a language instruction l. The observation contains agent-view images, wrist-view images, or both, depending on the model. We consider UADA [1], an untargeted
attack that optimizes an adversarial patch δ to make predicted actions deviate from the groundtruth actions. Applying the patch yields an attacked observation otadv = A(ot, δ), while leaving l unchanged.

Overview. We use a TopK SAE [9] to analyze how adversarial patches affect internal VLA representations. Our method suppresses a selected attack-related feature only when an attack is detected, aiming to improve robustness while limiting performance degradation under benign conditions. The method consists of three components: 1 identifying an attack-related feature using an SAE, 2 detecting adversarial patches with a linear probe, and 3 conditionally suppressing the selected feature based on the detection result.

4 Experiments

4.1 Experimental Setup
Models and Benchmark. We evaluate π0.5 [10] and SmolVLA [11] on LIBERO-10 [8]. For π0.5, we use a model that uses only the agent camera, while SmolVLA uses both agent and wrist cameras. Each main evaluation setting is evaluated on 50 initial states for each of the 10 tasks, for a total of 500 rollouts.

Attack Setting. We use UADA [1] targeting degree of freedom (DoF) 1 and generate one universal adversarial patch for each victim model. Our main evaluation considers intermittent attacks in which the patch appears n = 3 or n = 10 times during each rollout.

Defense and Comparisons. For each victim model, we identify an attack-related SAE feature and train a logistic regression probe to detect patch presence from internal representations. At inference time, our method suppresses the selected feature only when the probe detects the patch. We compare against the attacked policy without intervention (Baseline), continuous intervention without detection (w/o Det.), and intervention applied only when the patch is actually present (w/ Oracle Det.). The probe threshold is set on separate construction data to keep the false positive rate below 2%.

Evaluation. We report task success rate (SR) as the primary metric. The selected SAE feature, probe, and intervention strength are fixed before evaluation. Details of SAE training, feature selection, probe training, and intervention settings are provided in appendix B.

5 Conclusion

We presented an SAE-based defense that suppresses an attack-related feature only when a linear probe detects an attack, without additional fine-tuning of the VLA policy. On LIBERO-10, conditional suppression improves task success under intermittent UADA attacks on π0.5 and SmolVLA, while causing less performance degradation under benign conditions than continuous suppression. Our results highlight the importance of selecting attack-related features and controlling when and how strongly to suppress them. On SmolVLA, however, the gains are modest, and benign performance still degrades. Future work should evaluate robustness to unseen attacks, and test the defense on physical robots.

A Related Work
A.1 Adversarial Patch Attacks and Defenses.
Adversarial patches are localized visual patterns that alter the predictions of image classifiers and object detectors [12, 13]. Prior work has made such perturbations robust to changes in viewing conditions, including physically realizable ones [14, 15]. Defenses include masking corrupted features [16], certified input masking [17], and patch localization and removal [18].
In VLA models, visual perturbations can affect successive actions and disrupt task execution. Wang et al. [1] introduced patch attacks that either increase action discrepancies, as in UADA, or manipulate robot trajectories. Subsequent studies attack visual embeddings and image–instruction alignment [2], design attacks spanning textual, visual, and cross-modal perturbations [19], craft universal patches that transfer across models, tasks, and viewpoints [20], and optimize patches using only a short prefix of an execution trajectory [3].
Existing VLA defenses either preprocess the input images or fine-tune the model. JPEG compression and Gaussian blur provide limited protection against the patch attacks studied in [3]. Xu et al. [2] adversarially fine-tune the visual encoder to align the representations of clean and perturbed inputs. Our method instead intervenes directly in internal VLA representations at inference time, keeping the input images and policy parameters unchanged.
A.2 Mechanistic Interpretability and Representation Intervention.
Sparse autoencoders (SAEs) decompose model activations into sparse features that can support mechanistic analysis [21, 9]. Their applications have extended from language models to visual concept analysis in CLIP [22, 23] and to cross-modal representation analysis in multimodal models [24].
Recent work has brought mechanistic analysis to VLA policies. Directions associated with motion properties can steer robot behavior at inference time [4]. SAE-based studies identify features associated with motion primitives, semantic concepts, and behavioral events, and test their influence through closed-loop interventions [5, 6]. These studies primarily examine nominal behavior, leaving the use of such features for adversarial defense underexplored.
Internal interventions have also served as defenses in vision and language models. In CLIP, Dyslexify [25] improves robustness to typographic attacks without fine-tuning by ablating attention heads that transmit typographic information to the CLS token. Suppressing specific SAE features in CLIP’s vision transformer also mitigates typographic attacks [26]. Such interventions can also affect benign inputs. In language models, amplifying refusal-related SAE features can improve resistance to jailbreaks but can also degrade performance on benign inputs [27]. Some studies limit this degradation. Adaptive activation steering defends vision-language models against jailbreaks from adversarial images by removing activation directions associated with harmful responses, adjusting the amount of removal for each input [28]. Conditional activation steering uses properties detected in hidden states to decide when to steer [29], and O’Brien et al. [27] show that conditioning SAE steering on a prompt-safety classifier mitigates the regressions on benign inputs.
Our work brings this conditional approach to adversarial patch defense in VLA models. We suppress an SAE feature associated with patch presence only when a linear probe on the VLA’s hidden state detects an attack. We evaluate this intervention in closed-loop robot control and measure its effect on task success under both adversarial and benign conditions.

SAE Training. Following the Dr. VLA implementation [5], we train a separate TopK SAE [9] for each candidate layer. The training data are representations from the residual stream, collected during clean LIBERO rollouts. At each sampled control step, we mean-pool the representation over tokens and use the resulting vector as one training example. As in Dr. VLA, we use a 1× expansion ratio, so the SAE latent dimension equals the dimension of the VLA representation. We use a smaller TopK sparsity than Dr. VLA, keeping K = 12 active latents for π0.5 and K = 6 for SmolVLA. We train each SAE for 6,677 optimization steps and follow Dr. VLA for all other architecture and optimization settings.

Attack-Related Feature Selection. We select the intervention target (ℓ⋆, j⋆) on 10 development rollouts, one per LIBERO-10 task, that are separate from the main evaluation. In each rollout, the patch is inserted at randomly sampled intervals. For each candidate layer-feature pair, we compute the Pearson correlation between the feature activation and the binary patch-presence indicator, separately for each rollout. We then select the pair whose correlation exceeds 0.6 in the largest number of rollouts and break ties by the mean correlation across rollouts.

Linear Probe Training. We train and evaluate probes on 100 rollout pairs, each consisting of a clean and an attacked rollout from the same initial state. These rollouts are separate from those used for feature selection and from the 500 evaluation rollouts, and we split them 60/20/20 into training, development, and test sets within each task. Frames without a visible patch are labeled negative and frames with a visible patch are labeled positive; each attacked rollout contains three 10-frame patch intervals. For π0.5, the probe is a class-balanced logistic regression on the token-mean-pooled prefix representation at layer 5 of the PaliGemma backbone (2048 dimensions), with the inverse regularization strength C chosen from {0.01, 0.1, 1, 10, 100}. For SmolVLA, the probe is a linear classifier trained with class-balanced binary cross-entropy and L2 regularization on the mean over prefix tokens, excluding padding, at layer 9 of the VLM backbone. For both models, we set the threshold τ on clean development data so that the FPR is at most 2%. Under this constraint, we select SmolVLA’s C to maximize the detection rate on patch intervals of 10 frames in the development set. We also train probes independently at other layers of the VLM and the vision encoder.

Intervention Strength. We apply Eq. (1) at the selected pair (ℓ⋆, j⋆) and set the strength λ separately for each experimental condition. We search λ ∈ {0.25, 0.5, 1, 2, 4}, adding {0.1, 0.2, 0.3} in finer-grained experiments, select λ on the development rollouts, and fix it before evaluation. In the main evaluation, we use λ = 0.3 for n = 3 and λ = 0.2 for n = 10 on π0.5, and λ = 0.2 for n = 3 and λ = 0.25 for n = 10 on SmolVLA. For SmolVLA, we use λ = 0.25 under benign conditions

C.3 Effect of Attack-Related Feature Selection

We test how the choice of the suppressed feature affects SR. For π0.5 at n = 10, we compare the selected feature with SAE features sampled randomly from layers deeper than the detection layer, keeping the detection and intervention settings identical. For each feature, we measure its mean Pearson correlation with patch presence and the SR obtained by suppressing it. As shown in Fig. 5, the selected feature has the highest correlation and yields the highest SR. Some random features also improve SR over the baseline, but by smaller margins, and others reduce it.

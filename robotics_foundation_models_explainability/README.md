# Explaining and interpreting robot foundation models

Literature review of explainability and mechanistic interpretability for robot foundation models:
vision-language-action models (OpenVLA, pi0, pi0.5, GR00T, SmolVLA), large diffusion and flow policies,
and world-action models. Self-contained: own uv environment and scripts, no dependency on the TabPFN or
synthetic-data work elsewhere in the repo. Scope and source choices are in `../DECISIONS.md` #21.

## Read this

- **`lit_review/robotics_fm_explainability_review.html`** - the review: standalone page with a table of
  contents, collapsible sections, charts and a per-paper table. Open it in a browser; it needs no other files.
- `lit_review/robotics_fm_explainability_review.md` - the same text as Markdown, citations resolved.

151 included works (85 core, 66 adjacent) plus 31 background references, searched 2026-10-19.

## Contents

```
lit_review/
  review_source.md            review text with [@arxiv_id] citation markers (edit this, then re-render)
  included.json               screening decisions: every included work, its section and tier
  reading_notes_schema.md     the structure every reading note follows
  notes/<id>.json             one structured reading note per downloaded paper (83)
  notes/_synthesis_{A,B,C}.md cross-paper syntheses written by the three readers
  notes/_digest*.md           condensed views of the notes, regenerated by notes_digest.py
  data/raw/                   search results, web sweep, reference-list chaining, search counts
  data/processed/             deduplicated + screened records, screening sheet, PRISMA counts,
                              provenance of included works, note statistics
papers/
  <id>.pdf                    83 included arXiv papers, title-checked (about 800 MB, gitignored; listed with URLs in papers/README.md)
  text/<id>.txt               extracted text (pdftotext)
  manifest.json               per-paper title match, size, section
  workshop/                   abstracts and pages of workshop-only works, with fetch status
scripts/                      the pipeline, in run order below
logs/                         per-script logs
```

## Re-running

From this folder (environment: `uv sync`; Python 3.12, `requests==2.34.2`; needs `pandoc` and `pdftotext`):

```
.venv/Scripts/python.exe scripts/lit_search.py --no-chain       # ~3 min: 16 arXiv queries + Crossref
.venv/Scripts/python.exe scripts/lit_screen.py                  # ~10 s, offline: dedup + rule screen
.venv/Scripts/python.exe scripts/build_included.py              # ~1 s (+ ~10 s first time: title-checks background refs)
.venv/Scripts/python.exe scripts/download_papers.py             # ~20 min first time, resumable
.venv/Scripts/python.exe scripts/lit_refchain.py                # ~1.5 min: arXiv ids from the PDFs' reference lists
.venv/Scripts/python.exe scripts/lit_screen.py                  # again, now including reference-list records
.venv/Scripts/python.exe scripts/lit_provenance.py              # ~1 s: where each included work came from
.venv/Scripts/python.exe scripts/fetch_workshop_pages.py        # ~1-3 min: abstracts of workshop-only works
.venv/Scripts/python.exe scripts/notes_stats.py                 # ~1 s: counts over the core reading notes
.venv/Scripts/python.exe scripts/lit_render.py                  # ~2 s: Markdown + standalone HTML
```

The web sweep (`data/raw/web_sweep.json`) and the reading notes were produced by agents and are not
regenerated by a script. `lit_search.py --reuse-keyword` adds Semantic Scholar citation chaining when
that API is reachable; on 2026-10-19 it was not.

## Known gaps

- No forward citation chaining (who cites the key papers): Semantic Scholar rate-limited, OpenAlex's keyless
  budget was spent. Run it once an OpenAlex login or Semantic Scholar key is available.
- Twelve core works are workshop-only; their OpenReview PDFs return HTTP 403 to scripts, so they were read
  from abstracts or listing summaries. A browser (Playwright) could fetch them.
- One screener, no agreement statistics.

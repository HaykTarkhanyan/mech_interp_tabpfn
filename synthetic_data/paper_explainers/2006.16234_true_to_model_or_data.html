1. The paper in one minute

The question. To compute Shapley values for a model, you must say what the model "outputs" when some features are unknown. One camp fills them in from their conditional distribution given the known features (observational), the other from their marginal distribution, breaking dependence (interventional). Each camp has called the other wrong. Which is right?

The answers.

  1. Neither, in general. The choice depends on the application: interventional values are "true to the model", observational values are "true to the data" (Sections 1, 4).
  2. An exact method for linear models. With Gaussian features, observational Shapley values of a linear model can be computed exactly; the exponential part is a matrix computed once, after which each explanation is cheap (Section 2, Eqs. 7-9).
  3. Correlation moves credit. Observational values split a coefficient's credit among correlated features, give credit to features the model never uses, and converge more slowly when estimated by sampling (Section 3, Figs. 1-2).
  4. Two real cases, two winners. For loan applicants who want to change the model's decision, interventional values work better; for finding the genes that drive drug response, observational values recover more true genes from a Lasso model (Section 4, Figs. 3-4).
My take, one line. The framing is right, short and widely used, and it is the standard citation for choosing an estimand. The evidence is thin: both "wins" are set up so the winning definition is also the scoring rule, and "observational" here means Gaussian with the sample covariance, not the data's true conditional distribution.

2. Background you need first

Shapley values for a prediction. Treat the features as players and the model's output as the payout. A feature's Shapley value averages how much the output changes when it joins every possible group of the other features (Eq. 1). The catch: the model needs a value for every feature, so "only the features in S are known" has to be defined, through a value function v(S).

The two value functions of Section 1.1 (Eqs. 2-3) and the paper's names for them.

The arguments each camp makes (Section 1.2). Against observational values: they give credit to features the model never uses, violating the "Dummy" axiom proposed by Sundararajan and Najmi. Against interventional values: they evaluate the model on "impossible data points" off the data manifold, when breaking dependence creates combinations that never occur.

For a linear model f(x) = βx + b, the interventional Shapley value is simply φi = βi(xi - μi) (Eq. 4). The observational value needs conditional expectations of the unknown features, which is the hard part.

3. Finding 1: exact observational Shapley values for linear models

What they did (Section 2.2). Assume the features are multivariate normal, x ~ N(μ, Σ). Then E[x | xS] has a closed form (Eq. 7), and because a linear model commutes with expectation, the observational Shapley value is a sum of such conditional means over all feature orderings. Factoring that sum gives φ(f, x) = β T(μ)μ + β T(x)x (Eq. 9): two matrices that depend only on Σ, not on the instance.

Cost. Computing T(μ) and T(x) is exponential in the number of features, O(|N|³ 2|N|), but done once; after that each explanation is a few matrix multiplications. The matrices can also be approximated by sampling orderings, which "converges much faster" than sampling each explanation separately. This is the "correlation_dependent" linear explainer in the shap library (footnote 1).

My take. A genuinely useful trick, and the reason linear models are a good testbed: one exact observational reference per covariance matrix. It is exact only under the Gaussian assumption; with real data the paper plugs in "the sampling covariance and mean" (Section 3.2), so the reference is the Gaussian approximation of the data's conditionals, not the conditionals themselves. How sure: high.

4. Finding 2: correlation moves credit, even to unused features

Simulation (Section 3.1, Fig. 1). The model is f(x) = 1·x1 + 2·x2 + 3·x3 with standard normal features, explained at x = (1, 1, 1). With independent features the observational values are exactly (1, 2, 3), the same as interventional ones, and sampling estimates converge at once. With correlation, "correlation splits the β as credit between correlated variables" and "higher levels of correlation leads to slower convergence" of sampled estimates (20 repeats per sample size).

Real data (Section 3.2, Fig. 2). NHANES, 5-year mortality, 25,535 people. A linear model uses age, income ratio, systolic blood pressure and waist circumference (test AUC 0.772), but not BMI. Interventional values give BMI nothing. Observational values depend on which features are listed as players: with BMI added to the explanation, BMI gets importance through its correlation with the others, and the other features' importance drops. The authors note this can reveal a model's hidden dependence on an excluded sensitive feature.

My take. The BMI example is the key fact for any benchmark: observational values are not a property of the model alone. They change with the set of features you choose to explain, so "the" observational ground truth exists only once that set is fixed. The demo below shows both effects. How sure: high.

5. Finding 3: two use cases, two winners

True to the model: loans (Section 4.1, Fig. 3). A logistic regression predicts default on LendingClub data. For each applicant, rank features by their Shapley value and set them, one at a time and up to 10, to their mean; the faster the predicted log odds of default fall, the better the explanation. Interventional values lower the odds "much more" than observational ones, because observational values send applicants to change features the model does not use. In Fig. 3, after 10 changed features the mean change in log odds is about -15 for interventional and about -1 for observational, with wide, overlapping standard-deviation bands (approx.).

True to the data: genes (Section 4.2, Fig. 4). Take real RNA-seq data from leukaemia patients (1,000 genes), choose 40 genes at random as "causal" and simulate drug response as their sum plus Gaussian noise. Fit a Lasso, rank genes by mean absolute Shapley value, and count true genes found at each rank. Observational values recover more true genes than interventional ones: at rank 300, about 29 of the 40 against about 16 (approx., Fig. 4 left, single curves without error bands). But interventional values on an Elastic Net model do about as well, and that took "a matter of seconds" against 6 hours for the observational matrices with 1,000 samples on a 2018 MacBook Pro.

My take: each test is built for its winner. In the loan test, the score is the drop in log odds from mean-imputing a feature, which for a linear model is exactly βi(xi - μi), the interventional Shapley value; the paper says as much ("the interventional approach will first change a feature i where |βi(xi - μi)| is largest"). In the gene test, the truth is data-level (which genes generated the label), which is what observational values target. The paper's conclusion, that the estimand should follow the question, is right, but these experiments illustrate it rather than test it. The same pattern decided the winners in OpenXAI, Looking Glass and the 2026 synthetic ground-truth framework (see those explainers). How sure: high.

6. Try it: who gets credit

Exact computation, the paper's Section 3.1 example plus one feature: f(x) = 1·x1 + 2·x2 + 3·x3 + 0·x4 on standard normal features, explained at x = (1, 1, 1, 1). Interventional values are β_i·x_i. Observational values enumerate every coalition with the Gaussian conditional mean E[X | X_S = x_S] (Eq. 7), once with x1-x3 as the players and once with x4 added as a fourth player.

7. My critique

What's good. It replaced a fight about which value function is "correct" with the better question of what the explanation is for. The exact linear-Gaussian algorithm is practical and shipped in shap. The NHANES example makes the dependence of observational values on the player set concrete, and the Elastic Net result is a useful reminder that modelling choices can do what an attribution method does, far more cheaply.

8. How it connects to your work

Everything in this section is my own analysis.

It is the citation for your estimand. The transfer pilot scores explainers against interventional SHAP of the trained model (DECISIONS #22), the "true to the model" choice. That fits the question "does a benchmark rank explainers of a trained model correctly". Cite this paper when you state it, and say plainly that the conclusions are about that estimand.

It is also the strongest argument for realistic generators. An interventional truth of a fixed model barely depends on how features co-vary, since dependence between known and unknown features is broken by definition. An observational truth depends on it entirely. So the estimand for which realistic dependence matters most is the observational one, and that is where a data-fitted benchmark adds the most over Gaussian worlds.

ARF makes the observational truth computable. In a generator world, the generator is the true distribution, so E[f(X) | XS = xS] can be computed by sampling the generator's own conditionals. That is why XAI-BENCH used Gaussians. An ARF can do the same with realistic marginals and dependence, which is what conditional sampling (forge(evidence=...), upstream arfpy issue #5, the candidate next feature for your fork) would provide. With it, the pilot could add an observational truth arm without changing anything else.

A test to expect. Chen et al.'s Fig. 1 shows sampling estimates of observational values converge more slowly under correlation. If you add that arm, explainer rankings should depend on dependence much more than under the interventional estimand.

9. Glossary
Value function v(S)What the model "outputs" when only the features in S are known; Shapley values average its changes.
Interventional valueUnknown features drawn from their marginal distribution, ignoring dependence; "true to the model".
Observational valueUnknown features drawn from their distribution given the known ones; "true to the data".
Dummy axiomA feature the model never uses must get zero attribution.
Off-manifoldFeature combinations that never occur in real data, created when dependence is broken.
Lasso, Elastic NetLinear regression with an L1 penalty (picks one of a correlated group), or L1 plus L2 (spreads weight across the group).
NHANESUS National Health and Nutrition Examination Survey.
